# 💼 Симулятор Бизнесмена

Idle-инкременталка в браузере: начинаете с ручных сделок, открываете ларёк с шаурмой,
а заканчиваете мегакорпорацией, люксом и публичным размещением на бирже.

Сделано на **React 19 + Vite**, без сторонних UI-библиотек.

## Запуск

```bash
cd business-sim
npm install
npm run dev
```

Игра откроется на [http://localhost:5173](http://localhost:5173).

Сборка и предпросмотр:

```bash
npm run build
npm run preview
```

Проверка игровой логики (экономика, цены, престиж):

```bash
npm test
```

## Механики

### Бизнесы и прокачка

- **10 бизнесов** в 3 категориях (потребительский, индустрия, технологии/финансы): от ларя с шаурмой
  до космической компании и мегакорпорации. Цена каждой следующей точки растёт +15%.
  Покупка пачками: `×1`, `×10`, `×100`, `МАКС`.
- **Три ветки прокачки** каждого бизнеса:
  - **Оборудование** — +15% к доходу за уровень, цена ×1,5;
  - **Персонал** — +12% за уровень, цена ×1,2;
  - **Маркетинг** — +10% за уровень, цена ×1.
  - Цены прокачки растут геометрически (×1.8–×2.0 за уровень).
- **Менеджер** — нанимается один раз за фиксированную цену (≈60× базовой цены бизнеса, следующий
  стоит в 2 раза дороже) и даёт **+50%** к доходу всех точек этого бизнеса. На каждый бизнес можно
  нанять до 3 менеджеров (итого до +150%).
- **Синергия категорий** — каждый бизнес принадлежит к категории; каждые 10 точек в категории
  дают +5% к доходу всех бизнесов категории (максимум +50%).
- **Улучшения бизнеса** — отдельные карточки: требуют покупки N точек бизнеса, дают ×2–×3 к доходу.
- **Улучшения клика** и **глобальные** (усиление всего дохода) — открываются после заработка.

### Кейсы

- **🎭 Сценарии** — scripted stories с выбором в новой вкладке: франшиза, выход на орбиту,
  поглощение, кризис ликвидности, бренд. Решения могут открывать новые точки бизнеса,
  вливать капитал, платить/получать фиксированные суммы или давать временные бусты.
- **🎁 Лут-кейсы** — платёж за открытие → случайный дроп: деньги или предметы роскоши/машины
  (спорткар, часы, яхта, остров, самолёт, клуб, крупные суммы). Две таблицы: «Премиум-кейс»
  (5 млн ₽) и «Легендарный кейс» (50 млн ₽). Шансы выпадения денег/предметов зашиты в таблице.

### Финансы: биржа, недвижимость, люкс

- **Биржа** — 6 активов: 4 акции, сырьевые товары, криптовалюта и «Космос». Цены колеблются
  вокруг базовой (шум 0.4%–2.5%), с историей последних 40 цен (sparkline). На бирже можно купить
  и продать доли портфеля (10%–100%). Дивиденды приходят со стоимости портфеля (~0.6% в минуту).
- **Недвижимость** — 6 объектов (от студии до небоскрёба): покупаются с множителем ×1.6 за новую
  точку, дают пассивный доход и прибавляют **статус**.
- **Люкс** — 6 предметов роскоши (часы, спорткар, яхта, самолёт, остров, клуб): покупаются один
  раз и дают статус навсегда (после IPO статус сохраняется).

### Статус и репутация

- **Статус** = сумма очков недвижимости и люкса. +0.25% к общему доходу за каждое очко.
- **Репутация** — накопление через IPO: +1 очко за каждые 1 млн заработанного за забег.
  +10% к доходу за каждое очко. IPO обнуляет деньги, бизнесы, прокачку, менеджеров, недвижимость
  и портфель — но сохраняет репутацию, достижения и купленный люкс.

### Случайные события

- Появляются в сайдбаре раз в ~90 секунд, когда есть доход и заработано > 5 000 ₽,
  действуют 25 секунд.
- Варианты: вирусный ролик (+50%), крупный контракт, бум рынка (+35%), инвестор (+90 сек
  денег при −25% дохода), налоговая проверка, поломка. Есть исходы с риском.

### Достижения

- 30 достижений, разбитых по зонам: сделки, бизнесы, прокачка, деньги, доход, IPO, репутация,
  менеджеры, прокачка точек, недвижимость, статус, трейды и события.

## Структура

```
src/
├── App.jsx                 # состояние игры, тики (доход, рынок, события), покупки, IPO
├── main.jsx
├── styles.css              # тёмная тема, адаптив, модалки, биржа
├── components/
│   ├── Clicker.jsx         # кнопка сделки и всплывающие «+N»
│   ├── BusinessCard.jsx   # карточка бизнеса, шестерёнка, прокачка, синергия
│   ├── BusinessModal.jsx  # модалка прокачки/менеджера
│   ├── UpgradeCard.jsx
│   ├── PrestigePanel.jsx  # IPO и репутация
│   ├── AchievementsGrid.jsx
│   ├── AssetsTab.jsx       # недвижимость, люкс, статус
│   ├── StocksTab.jsx       # биржа, sparkline, сделки, дивиденды
│   ├── CasesTab.jsx        # сценарии-кейсы с выбором
│   ├── EventCard.jsx       # случайные события с выборами
│   └── OfflineModal.jsx
└── game/
    ├── data.js             # бизнесы, треки, менеджеры, недвижимость, люкс, акции, события, достижения
    ├── engine.js           # экономика, цены, производные, рынок, события
    ├── format.js           # форматирование чисел (К/М/Б/Т…)
    └── storage.js          # сохранения и офлайн-доход
```

Сбросить прогресс можно ссылкой в подвале страницы. Ключ сохранения:
`business-sim-save-v1`.

## Заметки по балансу

- Доход за 30 минут симуляции с прокачкой — порядка 64 млн ₽/сек на поздних этапах (для idle).
- Офлайн-доход: 50% дохода, максимум 4 часа.
- Дивиденды: 0.0001 от стоимости портфеля в секунду (~0.6% в минуту).
- Рынок: колеблется в пределах ×0.25–×4 от базовой цены, историю храним 40 точек.
